# Plan de metadatos de preservación — Cahíta Histórico Digital

## Propósito

Este documento define los metadatos mínimos necesarios para una futura liberación científica archivada del proyecto.

## Estado actual

La versión vigente permanece como `0.2.0-dev`. El recurso todavía se encuentra en desarrollo y no constituye una release científica archivada.

## Elementos requeridos para una release

- título persistente del recurso;
- autores y afiliaciones;
- versión semántica;
- fecha de liberación;
- repositorio de código;
- licencia;
- descripción metodológica;
- palabras clave;
- referencia a la fuente histórica ALC1737;
- commit exacto asociado.

## Relación GitHub–DOI

La futura preservación debe conservar la relación:

GitHub repository → release tag → archivo permanente → DOI

## Principio

La liberación debe preservar la trazabilidad completa entre la fuente histórica, los procesos computacionales y los datos derivados.
