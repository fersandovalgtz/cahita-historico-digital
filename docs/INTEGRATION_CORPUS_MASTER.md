# Integración del corpus maestro y liberación reproducible

## Propósito

Este documento registra la estrategia de integración de productos derivados externos al flujo canónico de Cahíta Histórico Digital (CHD).

## Criterio metodológico

Los productos derivados deben incorporarse únicamente cuando respeten la arquitectura existente:

- fuente histórica `ALC1737`;
- OCR y transcripción;
- candidatos lexicográficos;
- reconciliación;
- artículos estructurados;
- exportaciones reproducibles.

No se sustituirán las capas curatoriales existentes por datasets paralelos sin procedencia.

## Productos a integrar cuando corresponda

- exportaciones CSV/JSONL derivadas;
- perfiles interoperables;
- metadatos de liberación;
- documentación reproducible.

## Estado de transición

El repositorio mantiene actualmente una arquitectura avanzada de reconciliación lexicográfica y QA automatizado. La integración debe priorizar compatibilidad y trazabilidad antes que acumulación de archivos.

## Próximos criterios de salida

- sincronización de datos derivados con esquemas existentes;
- validación automática;
- documentación de procedencia;
- preparación de release científica.
