# Cahíta Histórico Digital — Auditoría de sincronización documental

## Objetivo

Registrar los criterios de coherencia documental previos a una futura versión estable del recurso.

## Documentos que deben permanecer sincronizados

- README.md
- CITATION.cff
- CHANGELOG.md
- ROADMAP.md
- RELEASE_CHECKLIST_v1_0.md
- RELEASE_CANDIDATE_MANIFEST_v1_0.md

## Criterios de consistencia

1. La versión declarada debe coincidir entre documentos.
2. Las métricas de cobertura deben provenir de una fuente canónica.
3. Las capas de datos deben mantener separación entre evidencia histórica, procesamiento computacional e interpretación.
4. Las versiones de desarrollo no deben presentarse como releases archivadas.

## Estado actual

El proyecto permanece en fase de desarrollo (`0.2.0-dev`). La transición a una versión estable requiere cierre de criterios de release, congelamiento de artefactos y preservación permanente.

## Próximo bloque

- auditoría final de métricas;
- congelamiento de versión candidata;
- preparación de release GitHub/DOI.
