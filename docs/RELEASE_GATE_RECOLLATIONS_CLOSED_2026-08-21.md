# Cierre del gate v1.0 de recolaciones

Fecha: 21 de agosto de 2026.

El gate de release asociado a las 22 remisiones `Buſca` clasificadas como `source_or_destination_requires_recollation` queda cerrado **por disposición explícita de incertidumbre**, no por resolución filológica.

Estado fijado para v1.0:

- 22/22 casos preservados con identidad exacta respecto de la cola canónica;
- 8 `A_unique_strong`, 4 `B_multiple_strong`, 10 `C_no_strong`;
- `disposition=frozen_open_uncertainty`;
- `canonicalAction=none`;
- 0 destinos seleccionados;
- 0 cambios del grafo canónico;
- `humanVerified=false` en 22/22;
- `philologicalResolutionStatus=open`;
- `facsimileResolutionClaimed=false`;
- `ocrAcceptedAsFacsimileSubstitute=false`.

Esta disposición permite una v1.0 técnica y científicamente publicable dentro de su alcance declarado, manteniendo la obligación de reabrir los casos cuando exista cotejo directo del mismo testimonio o revisión filológica humana trazable.

Tras este cierre permanecen sólo dos gates de release: (1) tag/changelog/metadatos finales y congelamiento de bytes; (2) preservación, GitHub Release y DOI.
