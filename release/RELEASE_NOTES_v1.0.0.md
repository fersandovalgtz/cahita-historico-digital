# Cahíta Histórico Digital v1.0.0

Primera release científica estable del alcance técnico declarado de Cahíta Histórico Digital para `ALC1737`, el *Arte de la lengua cahita* impreso en México en 1737.

## Contenido principal

- 2,302 artículos lexicográficos históricos en 211 archivos canónicos JSONL.
- 2,072/2,072 candidatos computacionales canónicos reconstruibles.
- Vocabulario p.133–177 reconciliado 45/45; Phase II p.145–177 cerrada técnicamente 33/33.
- 150 remisiones `Buſca`: 60 aristas estrictas `exact_unique`, 90 `not_located` con revisión explícita y 4 ciclos estrictos.
- 22 casos de recolación conservados como incertidumbres abiertas explícitas: 8 A / 4 B / 10 C; 0 destinos seleccionados por la capa v1 y 0 cambios canónicos.
- 14/14 ocurrencias de `Lo miſmo` separadas del grafo de remisiones y conservadas sin inferir su función exacta.
- 302 objetos gramaticales, 1,215 filas de evidencia y 371/371 unidades numeradas realmente impresas representadas.
- Proyección TEI Lex-0 0.9.5: 2,302 entradas, 2,221 citas de traducción, 150 remisiones y 60 `@target` estrictos, validada externamente con Jing.
- 26 contratos v1.0 congelados por SHA-256 y freeze byte-exacto de los datos científicos seleccionados para esta versión.
- Paquete de release determinista que incorpora datos canónicos congelados, derivados reproducibles, manifiestos y metadatos de citación.

## Alcance científico

Esta release es técnica, reproducible y publicable dentro del alcance documentado. No se presenta como una edición filológica íntegramente revisada por especialistas. Los estados de revisión humana se conservan sin inferencia (`humanVerified=0` donde corresponde) y las incertidumbres se mantienen visibles.

El facsímil histórico no se incorpora ni se relicencia como producción propia del proyecto. OCR y semejanza diagnóstica no sustituyen el cotejo directo del mismo testimonio.

## Preservación y DOI

La release de GitHub se publica con tag `v1.0.0`. El depósito archivístico y el DOI de versión/Concept DOI constituyen el gate de preservación posterior. Ningún DOI se declara hasta que sea efectivamente asignado por el repositorio de preservación.
